# Peripheral Desk · 外设控制中心

Rust + Win32 原生 Windows 外设设置与电量工具。黑灰色界面、红橙强调色、两级设备页面，无浏览器运行时。

## 下载与使用

在 [发布页面](https://github.com/chenran0408/peripheral-desk/releases) 下载 `PeripheralDesk-*-windows-x64.zip`，解压到可写文件夹，运行 `PeripheralDesk.exe`。**0.4.0 起主程序与设备插件分开发布**：打开“驱动仓库”，按需安装设备插件。鼠标、键盘通常无需额外系统驱动或管理员权限。G2 Pro 音效复用本机已安装的 HECATE / C-Media 组件，见下文。

- 首页选择设备：在线亮色、离线暗色、接收器在线但无有效读数时显示待唤醒。
- 左键托盘图标显示设备电量；右键可打开主页、刷新或退出。
- 点右上角关闭会留在托盘。彻底退出请使用托盘菜单或首页的“退出程序”。
- 设置停止调整 1.5 秒后保存，并从设备读回核对；失败会显示提示。修改后只重新读取对应设备，避免等待其他设备唤醒。
- 默认每 60 秒刷新，低于 20% 时提醒。工具设置中可调整。
- 更新时退出程序，用新版文件替换旧版，保留同目录 `data` 文件夹即可。

## 已接入设备与功能

| 设备 | 电量/充电 | 基础设置 | 已移植的更多设置 |
| --- | --- | --- | --- |
| 炼狱蝰蛇 V3 专业版 | 支持 | DPI、5 档 DPI 表、回报率、休眠 | 省电阈值；原始标记为 0 的映射槽改键；本机已验证前进侧键，其他槽保持只读 |
| 迈从 A5 Ultra 初代 | 支持 | DPI、1～6 档 DPI 表、回报率、休眠及不休眠 | 防抖、LOD、Motion Sync、直线修正、波纹控制、角度、电竞模式；六键映射及有限单次键盘宏 |
| 迈从 G75 Pro | 支持 | 回报率、休眠及不休眠、灯效 | 亮度、速度、单色/多色与预设色、Win 锁、Mac 模式、低延迟；普通层与两层 Fn 映射、逐键 RGB |
| 漫步者 G2 Pro | USB 供电，无电池 | GAMING / CHAT / 麦克风音量、麦克风静音 | 十段 EQ 与预设库、环绕、增强、降噪、变声、音效 JSON；灯光开关及常亮/呼吸/彩虹编排 |

DPI 滑块修改当前档位；点档位按钮切换。A5 减少档数会保留未启用槽位的 DPI 数值，若任一连接的当前档位超出新档数，会提示先切换到保留范围，再允许缩减。传感器角度提供 −30°～30° 的常用档位。

G75 的亮度、速度和颜色只在当前灯效支持时开放：常亮不提供速度，风车/花开不提供亮度与速度，彩虹/瀑布等不提供单色设置。支持颜色的灯效可切换单色/多色；单色可选红、橙、黄、绿、青、蓝、紫、白。设备中已有的其他颜色会保留，选择预设后才替换当前灯效的颜色。Mac 模式启用时解除 Windows 键锁定，并暂时禁用锁定选项。

上表描述已实现的功能入口，具体可写项目取决于设备回复和插件能力，实机验证范围见 [验证记录](docs/TESTING.md)。A5 宏仅单次、最多 13 个编码事件，支持键盘按下/释放与延时；只编辑确认空白或与本工具已保存宏匹配的页，未知非空宏页保持只读。G75 板载宏协议尚未完整确认，不开放宏写入。雷蛇改键须先收到有效主键回复；仅开放原始标记为 0 的槽。本机已验证前进侧键，其他标记的槽和左键保持只读。更多边界见 [功能表](docs/FEATURES.md)。

“软件宏”提供独立的常驻执行方式：将非左键/非 Fn 的可写按键临时映射为保留触发键，按键后播放一次键盘动作。最多 128 步、总延时 30 秒，支持按下/释放与延时，不并发、不递归；需保持主程序运行。启用前保存原绑定，停用或退出时尝试恢复并核对。若设备断开导致恢复失败，记录保留，下次打开软件宏页面继续恢复。保存或导入定义不会自动启用、不会自动播放。A5 返回长度为零的宏页无法完整备份时，板载宏入口保持禁用，可改用软件宏；两者不混称。

## 插件安装与更新

设备插件源码和独立发布在 [peripheral-desk-drivers](https://github.com/chenran0408/peripheral-desk-drivers)。插件为用户态 DLL，主程序在隔离进程调用；异常或超时会报告错误，避免直接拖垮主界面。主程序与插件分别选择稳定/预览通道，版本独立更新。驱动仓库支持安装、更新、卸载和回退上一版本；操作前备份本地配置，卸载保留设备配置。

稳定版目录固定在 `catalog-stable` release，预览版目录固定在 `catalog-preview` release，文件为 `catalog-stable.json` 或 `catalog-preview.json`，另附同名 `.json.sig`。预览发布不会覆盖稳定目录。程序用内置公钥验证目录，再核对 ZIP、DLL 的 SHA-256 和兼容范围。

离线安装从 [插件发布页](https://github.com/chenran0408/peripheral-desk-drivers/releases) 下载设备 ZIP、对应通道目录 JSON 与 `.json.sig`，放在同一文件夹，再选择离线安装。三者须来自相互匹配的受信发布；自行修改 JSON 或未签名构建产物不能作为安装目录。

## 配置备份与诊断

“配置与诊断”按设备导出本地缓存、已保存的改键/颜色/音效记录、软件宏定义、A5 宏或 G2 EQ 库。导出可能含个人按键宏，请自行保管；不含 SDK 路径、驱动文件、HID 路径或序列号。软件宏导入只恢复定义，保留本机待恢复绑定，不导入另一台机器的恢复记录。

导入先检查设备标识与格式、备份现有文件，再恢复本地记录；**不会立即修改设备**。独立“应用到设备”只处理能读到基线并安全恢复的已支持项目，跳过项列出原因。DPI 等状态快照不会自动变成写入命令；未知宏或无法完整恢复的设置不会强行应用。未知 JSON 字段会保留，空数组可清空对应列表；本地写入失败尝试恢复原文件，设备写入失败尝试恢复已尝试项，断开、崩溃或超时仍可能阻止恢复。

匿名诊断仅包含程序/插件版本、数字 VID/PID、usage、报告长度、连接状态与概括错误，不含设备路径、序列号、用户名、SDK 路径或原始按键宏。反馈问题优先使用匿名诊断，避免上传个人配置。

## G2 Pro 使用方式

保留官方 USB 声卡驱动和音效组件，关闭官方控制中心即可。新界面在“音量、均衡器、环绕、增强、语音”中管理设置，不需要官方界面保持运行。不会更换声卡驱动，也不会修改默认播放设备、启动录音或开启麦克风监听。

首次打开耳机页面，点击“连接音效组件”，选择官方安装目录里的 **x64 / osConfLib.dll**。旧版控制中心常见位置为 `CPL/Driver/x64/vista/osConfLib.dll`，HECATE 1.1.44 的目录为 `CMSDK/x64/Vista/osConfLib.dll`。仅支持已验证的 C-Media 1.0.8.0 x64 文件；程序会校验文件内容，并在隔离进程调用，超时后结束该进程。

EQ 是 GAMING 通道的 30 Hz～16 kHz 十段均衡器，范围 ±20 dB、每格 1 dB。EQ 关闭时调整只保存频段数值，启用后才参与处理。其他效果也需要先打开对应开关。Windows 关闭音频增强时不会擅自启用它，音效控件会保持不可用。

EQ 预设库可保存当前、切换、重命名和删除，每套只包含十段与 EQ 开关。默认“平直/人声清晰/低音增强/游戏细节”为工程起点，不是官方或声学校准预设。记录使用稳定编号，重命名保留未知扩展字段，删除会实际移除所选记录。

耳机页的“导出音效”可保存当前读到的音效为 JSON，“导入音效”可恢复这些参数。配置仅包含 G2 Pro 音效，不包含系统音量、麦克风静音、组件路径或驱动文件；导入前检查型号、文件版本与数值范围。写入逐项读回，遇到错误尝试恢复此次已修改的原值，并报告恢复结果。导出采用临时文件替换，避免保存中断留下半份配置。

G2 灯光可读回开关；模式、速度和 RGB 显示本工具上次成功发送的记录，设备未提供这些参数的完整读回。没有可恢复的本工具记录时，配置批量应用跳过灯效。灯光保存不等于已验证全部物理显示效果。

便携包和插件不附带官方 DLL、驱动、安装包或付费算法；缺少必要组件时无法提供原有音效。不同版本组件需要重新验证。麦克风监听和部分高级环绕尚未开放。配置不能替代必要组件；参数读回不等于完成听感验证。

## 已验证范围

实机：G2 Pro `35BB:A100`（C-Media 驱动 11.1.1.6、SDK 1.0.8.0），雷蛇 `1532:00B7` 接收器、A5 Ultra `3837:100C` 接收器、G75 Pro `3554:FA09` 接收器。G75 的通用接收器还会读取型号签名，匹配 G75 Pro 后才开放操作。

雷蛇有线 `1532:00B6`、G75 `41E4:2001` 为协议入口，尚未完成对应硬件验证。A5 V2/V3、A5 Pro Max 和其他 G75 版本不会按本型号强行适配。蓝牙不在本版本支持范围。

鼠标休眠时无法保证有新读数，请先移动设备再刷新。A5 和 G75 可主动选择“不休眠”；这会增加耗电，程序不会在日常启动时擅自修改设备的休眠设置。雷蛇没有已验证的关闭休眠选项。避免雷云或 M HUB 的设备页面同时与本工具通信。灰色缓存电量会标明“上次电量”。

## 编译与测试

Windows 10/11 x64，安装 Rust stable 和 Visual Studio C++ Build Tools（含 Windows SDK）。

```powershell
cargo check --locked
cargo test --locked --lib
cargo build --release --locked
powershell -File scripts/package.ps1
```

常规测试不访问设备。标记 `ignored` 的实机测试按项目需要对应设备已连接并唤醒；部分测试会临时切换设置并恢复原值，不在 CI 自动运行。详细项目与恢复要求见 [验证记录](docs/TESTING.md)。

```powershell
cargo check --locked --no-default-features --features driver-runtime --lib
cargo test --locked --no-default-features --features driver-runtime --lib
```

命令行：`--hidden` 只启动托盘；`--battery` 电量浮窗；`--once path.json` 一次状态；`--diagnose path.json` 匿名诊断；`--configuration export mchose-a5-ultra a5.json` 导出配置；`--configuration import mchose-a5-ultra a5.json` 仅导入本地。

桌面主程序使用默认 `desktop` feature；协议开发使用独立 `driver-runtime` feature。CI 工作流见 `.github/workflows/core-build.yml`，常规测试不访问硬件。只在必要时按验证文档选择具体 `ignored` 项目，不在 CI 运行实机写入。

## 扩展设备

[适配指南](docs/ADAPTER_GUIDE.md) 提供接入步骤、协议适配器契约、能力声明、测试及发布要求。核心结构：

```text
主界面 / 托盘 → backend / DeviceSession → 插件管理器
                       ↓                      ↓
               model / controls       隔离进程 → 设备 DLL
                                              ↓
                                       协议 codec / HID
```

新设备在独立插件仓库提供设备描述、DLL 和能力声明，主界面根据元数据生成卡片和设置，不必为每个型号复制窗口。通用模型或编辑器新增语义才需要协调主程序更新。设置写入后只刷新目标设备；主页和定时刷新读取完整列表。设备协议问题和适配 PR 优先提交到插件仓库，界面、更新管理、备份问题提交本仓库。
