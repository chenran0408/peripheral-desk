# 迈从设备怎样连接外设盒

在「设备调节」点选迈从设备，已经迁移的设置直接在主窗口打开。要用其他原有鼠标、键盘和音频编辑器，选择「更多原厂功能」；「设备调节」右上角也可打开「本地 M HUB」。从单台设备进入会携带点选的接收器，顶栏「切换设备」可另选设备。

## 哪些操作可以直接用

| 原有功能 | 连接方式与可用范围 |
| --- | --- |
| 改键、板载配置、板载宏、逐键灯光 | 原编辑器使用外设盒的 Windows HID 通道读写已匹配的设备，保留键盘布局、预览和动效。可选的设置、槽位、宏动作由实际型号决定。 |
| 鼠标 DPI、回报率、按键和休眠 | 识别到在线鼠标后进入该型号的原有页面。睡眠中的鼠标可能只有接收器可见，移动鼠标后再看状态。 |
| 磁轴键盘 | 本地磁轴页面可复用主窗口中的设备对象。可用的触发设置和布局依型号与固件而定。 |
| 音效、跨设备联动 | 驱动中心保留随包的型号页面。屏幕和音频采集仍由系统管理；厂商桌面服务专属的进程联动等功能另见[兼容表](MHUB-COMPATIBILITY.md)。 |
| 固件与账号 | 本版本提供本地设备调节。厂商 OTA 与外部升级器未接入；账号与云同步不在本地驱动中心范围内。 |

## 连接和验证范围

内置版将 M HUB 的设备枚举、打开、关闭、Feature 报告、Output 报告、异步 Input 报告和插拔事件接到 Windows。用户无需为受支持的设备逐一配对或在网页中授权。设备查找依据随包的厂商型号表与配置接口，共 103 组 VID/PID、145 条接口匹配规则。共用接收器仍需设备自身提供身份，不能凭接收器的外观或 ID 确定型号。其他型号可使用原有的「连接设备」入口；手选旧的个人网页副本沿用其原有连接方式。

本项目在没有既有浏览器授权的新配置中同时枚举到初代 A5 Ultra 和 G75 Pro 的实体接收器，选择框调用次数为零。两台设备均通过 Windows 通道读回了电量。G75 Pro 在真实 M HUB 中完成型号识别，自动进入带普通层、Fn、Fn2 的原厂改键页。这次验证使用读取操作。各项设置的写入验证见[按功能列出的兼容记录](MHUB-COMPATIBILITY.md)。

本版依据随包主模块 `main-DIt5vAcV.js`、其设备过滤器和 `configCenter/custom/cardList.json`。更新型号匹配时同时核对连接方式、用途页与报告布局。[固定的来源版本](../installer/mhub/source.lock.json)
