# 0.4.x 本轮测试范围

0.4.3 的变更限于界面显示缓存：移除首页、设备详情和托盘重绘路径里的安装记录读取；启动和关闭驱动管理页时重新加载。Windows GNU 编译检查与格式检查通过。设备写入协议、更新器和配置格式未改，没有重复硬件写入测试，也没有宣称测得帧率或延迟提升比例。公开包另经发布流程的静态检查、软件测试和握手校验。

以下记录区分代码实现、设备读回和实际功能效果，不把其中一项当作全部通过。环境为 Windows x64，本机接收器或 USB 接口；历史参数回归见 [TESTING.md](TESTING.md)。

| 项目 | 本轮确认 | 尚未确认或限制 |
| --- | --- | --- |

雷蛇 `1532:00B6`、G75 `41E4:2001` 的入口、蓝牙及其他硬件版本不据此宣称实测兼容。G305 只读预览尚无本机硬件验证；ATK/VGN 的研究候选不等于可安装支持。见 [五品牌调查](https://github.com/chenran0408/peripheral-desk-drivers/blob/main/docs/PROTOCOL-RESEARCH.md)。

常规软件测试不访问硬件；实机项目按需单独运行，避免重复切换设备。设备写入会保留基线并尝试恢复，最终以独立读回结果为准，失败如实记录。本文不提供容易过期的累计测试数量，具体执行记录以对应版本的构建/验证结果为准。

0.4.2 桌面只显示已安装插件，不从开发机型号生成默认卡片。空安装、仅安装一个设备、旧版插件设置元数据兼容和插件异常隔离分别检查；这类软件检查不访问 HID，也不安装未选择的插件。
