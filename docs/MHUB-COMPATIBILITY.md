# 迈从驱动中心能做什么

安装 Windows x64 安装程序后，在「设备调节」点选自己的设备。G75 Pro、初代 A5 Ultra、0x4D 鼠标、CZ 有线磁轴键盘和兼容迈从音频设备都有按型号提供的原生编辑器。在「插件管理」选择预览渠道并安装自己的型号。要用其他原厂编辑器，打开「本地 M HUB」或设备页的「更多原厂功能」。内置网页离线可用。[下载安装程序](https://github.com/chenran0408/peripheral-desk/releases/download/v0.4.12-preview.5/PeripheralDesk-0.4.12-preview.5-windows-x64-setup.exe) · [本地工作区用法](MHUB-WORKSPACE.md)

[按型号查询原生功能、连接和验证范围](https://github.com/chenran0408/peripheral-desk-drivers/blob/main/docs/MCHOSE-NATIVE-FAMILIES.md)。

Windows 直连的设备范围、原版功能和验证记录见[本地连接说明](MHUB-NATIVE-TRANSPORT.md)。

以下对照适用于 2026 年 11 月 20 日固定的 M HUB 网页，入口文件为 `main-DbMO5C6u.js`，主程序块为 `main-DIt5vAcV.js`。设备型号、接收器代际、连接方式和固件共同决定设备页会显示哪些设置。连上某个共用接收器，不能据此判断整系列都能写入相同设置。

## 想改一台设备

| 想做的事 | 在外设盒中怎么用 | 已知范围与限制 |
| --- | --- | --- |
| Windows 直接连接 | 进入驱动中心即可发现匹配的设备。多台在线时可直接进入点选型号，或继续使用上次的型号 | 来自随包 M HUB 的 145 条接口规则，涉及 103 组 VID/PID。初代 A5 Ultra 和 G75 Pro 已在本项目实机读到电量。在无既有浏览器授权的配置中，同时发现两只接收器，并从 G75 Pro 入口自动打开原厂改键页，设备选择框出现 0 次。其他型号以协议与接口匹配记录为准。 |
| 查看电量、充电和连接状态 | 安装匹配的原生插件，在设备页或托盘查看。也可以在网页驱动内查看它识别到的设备 | 网页连接按钮已在 WebView2 中验证能调用一次 HID 设备选择请求。该次使用模拟授权结果。电池字段、更新频率和实际精度以各型号记录为准 |
| 调鼠标 DPI、档位、回报率或休眠 | 打开驱动中心的鼠标页。初代鼠标与新协议鼠标有各自的编辑器。初代 A5 Ultra 也可用原生插件调 DPI、回报率、休眠、防抖和抬升高度等项目 | 上游网页编辑器及两套型号表已打包，可离线加载。不同鼠标的档位数、DPI 范围、防抖及传感器开关各异；网页读写未在所有接收器上复验 |
| 鼠标改键、保存或切换板载配置 | 在鼠标页选择设备提供的配置槽，再编辑按键。网页里的本地模板也可用于编辑；要带到另一台电脑，须实际写入鼠标支持的板载槽 | 初代 A5 Ultra 原生插件有普通改键读回及恢复记录。该机测试时宏页长度为零，原生板载宏上传未开放。网页能进入宏编辑器，能否写入由该鼠标的协议和宏槽决定 |
| G75 Pro 再次改键 | 在驱动中心的改键页选择普通层、Fn 或 Fn2，再点选或拖放目标按键。再次打开会以本层板载读回为基础 | 在官网实际组件和解析器上，以模拟设备回复验证连续编辑、三层切换、未知键值、宏槽、保留槽与未命名尾部的保留；写入失败后重新读取。原生插件另有实体 G75 Pro 的 F13 绑定读回及恢复记录。网页修复未在实体键盘上重新写入 |
| 设置机械键盘灯效、逐键颜色和性能 | 匹配型号后进入键盘页，查看该型号提供的模式、亮度、速度和逐键设置。G75 Pro 原生插件另有回报率、休眠、Win 键锁定、Mac 模式等入口 | G75 Pro 原生逐键色与性能块有实机读回、恢复记录。相同外观的其他代际键盘需使用其自身布局、色表及接收器；其他型号网页写入未逐款实测 |
| 创建、编辑宏 | G75 Pro 点「板载宏」，选择普通层按键，添加键盘、鼠标按放和延时后写入。常驻软件宏仍有独立入口 | 本项目在标准无线接收器上传、绑定、读回单次宏并逐字节恢复；按住循环和按其他键停止已核对协议。物理按键触发、断电重连未在本轮验证。其他型号各按自己的宏槽和协议开放。 |
| 调整磁轴键盘 | 26 款 CZ 有线型号在「设备调节」直接打开原生键盘图。点选实体键，设置 RT、触发行程或 DKS、SOCD 等高级键。选择键位层后应用，读回显示实际保存的值。 | 键盘图来自对应型号及区域版本。可用功能按型号与固件开放。其余原厂预览布局仍在内置 M HUB 中。 |
| 调迈从耳机、音箱的声音、灯或屏幕 | 15 款耳机和音箱支持按当前实体设备选择播放或麦克风端点。V9 Pro 2、R9 提供三套十段板载 EQ。K20 系列提供灯效，K20 GT 另有屏幕开关、主题和颜色。 | 已在 Windows USB 音频端点验证读取和筛选。新增型号的板载写入来自固定原版协议，本批未逐台实机验证。THX 和 C-Media 的专有桌面音效及图片上传的实际范围见型号表。 |

各原生适配的具体范围与实机记录可在项目中查到。[原生功能表](FEATURES.md) · [设备实机验证记录](VALIDATION.md)

## 本地资料、联动和线上服务

| 功能 | 当前体验 |
| --- | --- |
| 本地配置与个性化 | 原生「本地模板」支持 G75 Pro、初代 A5 Ultra、17 款 0x4D 鼠标、26 款 CZ 磁轴键盘以及 V9 Pro 2、R9。按型号保存、选择、导入、导出、重命名和删除。个人 CSS 与网页交互脚本仍在本地 M HUB 使用。 |
| 键鼠测试、配对指引、设置与换肤 | 本地有键盘和鼠标测试页、常规设置、语言和外观入口。已核对测试页、宏页和常规设置的加载。设置里的「配对指引」提供操作步骤，不代表电脑可以重新绑定任意接收器。测试工具显示电脑收到的输入；改键后的板载保存要在设备上读回检查 |
| 多设备灯光联动、音乐灯效 | 保留了 LightSync 模块。上游的部分预览可申请浏览器画面或共享音频采集权限；需要系统音频时，还取决于所选共享源能否提供音轨。多台设备实际同步需要相应的灯光协议，并让驱动中心保持运行。本项目尚未在一组真实设备上验收完整联动 |
| 屏幕同步、游戏交互、跟随应用切换板载配置 | 上游的独立「屏幕同步」「游戏交互」页使用官方桌面客户端的显示器、游戏采样接口。按活跃应用自动切换配置也依赖桌面进程接口。外设盒 WebView 没有这些厂商桌面接口；这些桌面联动未接入。手动切换受支持的板载配置可独立使用 |
| 跨应用按键统计、热力图 | 上游热力图入口还有桌面客户端及环境或账号条件，物理键盘后台输入使用桌面接口。外设盒未开放这项后台统计。在测试页查看当前窗口收到的输入可独立使用 |
| 账号与云服务 | 设备设置和本地模板无需登录。账号、云同步和社区发布均在项目范围之外 |
| 获取社区模板 | 后续最多考虑一个按需获取公开模板的只读接口，目前尚未实现。已有的本地模板可继续编辑，原生插件的配置可在设备页导入和导出 |
| 商城、广告、反馈、下载官方客户端 | 这些厂商网络入口已从本地导航移除或屏蔽。外设盒的问题和设备适配反馈可在项目页提交。[提交问题](https://github.com/chenran0408/peripheral-desk/issues) |
| 固件版本、设备或接收器升级 | 有型号能读版本号。驱动中心未开放厂商的固件包下载、OTA 刷写及外置升级程序。外设盒的「检查更新」更新软件和设备插件，不会刷键盘、鼠标或接收器固件 |
| 断网使用 | 已安装的网页、协议、型号表和随包资源从本机读取；本地设备通信不需要登录。缺少的产品图不会从厂商站点补取。安装新的型号插件或下载新版本需要网络，或者提前取得相应离线包 |

设备页会根据实际设备决定可操作项目。上表中的“页面已核对”指实际加载本地页面；“模拟设备回复”指在原组件、原解析器上检查数据如何读写；原生插件对实体设备的验证范围单独列出。[固定版本的发布记录](https://github.com/chenran0408/peripheral-desk/releases/tag/v0.4.11-preview.15)
