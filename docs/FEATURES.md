## 改键与宏

雷蛇仅在主键读取返回有效左点击锚点后开放改键。左键固定；其他槽位编码未知时保持只读。写后核对配置不等于验证实际按键输出或断电保存。

A5 修改完整按键配置块中的对应项目，保留其他字节，并防止删掉最后一个主点击。宏仅单次、最多 13 个编码事件，支持键盘按下/释放与正延时，要求按键事件平衡；名称最多 20 个 UTF-8 字节。

A5 写宏前完整读取 63 字节原页及原名称。只有原页确认空白，或内容和本工具保存的宏匹配，才允许覆盖。未知非空页、未知多页格式拒写。修改失败尝试回写并核对原始宏页、名称和按键配置；恢复失败如实报告。

G75 每层映射块按实物 504 字节读取，前 96 槽用于可见布局，矩阵空位和尾部原样保留。支持已确认的普通键、修饰组合、媒体功能、鼠标按键与禁用，未知编码不自动归一化。物理 Fn 保留。宏页地址和完整备份尚未确认，不提供板载宏写入。

## 常驻软件宏

三款鼠标/键盘另有独立软件宏入口，需先读到有效可写映射。它把所选非左键、非保留 Fn 临时映射为 F13–F24，使用 Windows 热键捕获，再由本工具播放一次键盘动作；不能称为板载宏。其他应用已占用的触发热键不会使用。

支持最多 128 步、总延时 30 秒的平衡键盘按下/释放和正延时，不支持鼠标事件、循环和并发。F13–F24 不允许作为播放步骤，防止递归；取消或异常时尝试释放已按键。播放发往当时前台窗口，系统权限限制可能阻止输入。

启用先保存原绑定恢复记录，设备写后核对。停用、插件操作或正常退出先停止播放并恢复原绑定；恢复失败保留记录并提示，不谎称已经恢复。下次启动不自动重新启用，打开页面可手动恢复。保存、导入宏定义不会自动启用或播放。强制结束进程无法执行退出恢复。

A5 当前硬件的长度零宏页不能视作完整空页备份，板载宏写入因此保持关闭；软件宏不依赖该未确认协议。G75、雷蛇也不因此宣称板载宏已支持。

## 灯光与性能

A5 减少 DPI 档数保留未启用槽位；有线或无线当前档位会被删除时先拒绝写入。关闭休眠使用本型号确认的 0 值，不能推广为其他设备的通用值。

G75 性能块 128 字节、预设颜色块 490 字节；修改保存基线并完整读回，失败尝试恢复。常亮不开放速度，风车/花开不开放亮度与速度。关闭、彩虹、风车、瀑布、花开不提供单色/多色或单色预设。其他支持颜色的模式可选八个预设或保留设备原色。

逐键色使用 378 字节平面 RGB，每色 126 槽；只编辑可见键，保留其余槽位。应用会切换到对应自定义灯效，失败尝试恢复原颜色和性能配置。Mac 模式启用时清除 Win 键锁定，Mac 下拒绝开启该锁定。

G2 Pro 通过独立 HID 接口读取灯光开关。本工具可发送常亮、呼吸、彩虹编排参数，但设备只确认开关；颜色、速度、模式显示本工具上次成功发送的记录。未知原灯效无法完整回滚时，批量配置应用会跳过，不能将本地记录标为设备读回。

## EQ 与音效

G2 Pro 保留官方声卡驱动和已校验的 C-Media 音效组件，替换控制界面。EQ 库每套仅保存十段与 EQ 开关，可保存当前、应用、重命名和删除；默认四套是工程预设，不是官方或专业校准结果。预设稳定 ID 及未知扩展字段随保存保留，明确删除的记录不会恢复。

完整音效 JSON 与 EQ 库分开：音效 JSON 包含当前成功读取的效果参数，不含系统音量、静音、组件路径和驱动文件。导入先验证能力及范围，先关闭效果、调整参数、最后开关；每项读回，失败反向恢复全部已尝试项。崩溃、超时或拔出仍可能阻止恢复。参数确认不代表听感一致。

## 插件、配置与诊断

- 主程序和插件独立版本、独立通道。插件支持签名目录、包/DLL 校验、离线安装、更新、卸载及上一版本回退；调用在隔离进程内进行。
- 稳定/预览目录分别使用固定 `catalog-stable` / `catalog-preview` release；离线安装需要 ZIP、对应 JSON 与 `.json.sig`。
- 配置导出保存本地缓存和已保存的数据；导入只恢复本地，先备份，再原子替换，失败尝试恢复原文件。
- 未知 JSON 字段保留；数组由导入内容替换，空数组可清空。无法理解的字段留在存档，不下发设备。
- 独立“应用到设备”预读基线，仅处理当前可安全确认与恢复的改键、本工具宏、颜色、音效参数。状态快照中的 DPI 等不会自动写入，跳过项目明确显示。
- 匿名诊断只有版本、数字接口信息、连接状态和概括错误，不包含个人路径、序列号、原始按键或宏。普通配置可能包含个人宏，请勿当匿名诊断公开上传。

固件刷写、云账号、云配置、音乐灯效、进程联动、蓝牙和未明确列出的型号不在当前支持范围。
