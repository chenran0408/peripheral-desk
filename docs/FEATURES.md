# 原驱动功能移植进度

本版本提供电量、常用性能设置、部分原驱动高级设置和可复用框架。下表区分已接入与后续工作，避免把原驱动中的所有功能都显示成可用。

| 设备 | 本版本已接入 | 后续逐步移植 |
| --- | --- | --- |
| 雷蛇炼狱蝰蛇 V3 专业版 | 电量、充电、DPI 档位切换及当前档位编辑、回报率、休眠、省电阈值 | 按键重映射、宏、配置管理、Smart Tracking/非对称截止 |
| A5 Ultra 初代 | 电量、充电、DPI 档位切换及编辑、1～6 档数量、回报率、休眠/不休眠、防抖、LOD、Motion Sync、直线修正、波纹控制、传感器角度、电竞模式 | 按键重映射、宏、鼠标配置管理、独立 Y 轴编辑 |
| G75 Pro | 电量、充电、回报率、休眠/不休眠、灯效、亮度、速度、单色/多色、8 个单色预设、锁 Windows 键、Mac 模式、低延迟 | 普通层/Fn 层改键、宏、任意颜色编辑、逐键 RGB、键盘配置导入导出 |
| G2 Pro | GAMING / CHAT / 麦克风音量、静音、十段 EQ、环绕开关与空间大小、响度均衡、声音提亮、动态低音、人声清晰、麦克风 / CHAT 降噪、变声、音效 JSON 导入导出 | 灯光、监听、高级环绕模式 |

A5 减少 DPI 档数时，若有线或无线连接的当前档位会被删除，将拒绝写入并提示先切换到保留范围，避免固件自动改写未知字段。

当前参数编辑保留不相关字段，写入后读回确认。G75 修改性能设置时保留完整 128 字节配置，修改预设灯色时保留完整 490 字节灯色块中的其余字节；失败尝试回写原块。颜色预设仅编辑当前灯效的 RGB，未提供逐键灯编辑器。Mac 模式与 Windows 键锁定按原驱动规则互斥。

G75 常亮不开放速度，风车/花开不开放亮度和速度；关闭、彩虹、风车、瀑布、花开不开放单色/多色与单色预设。设备返回自定义颜色时保留原值，不将其误认为某个预设。

复杂改键与宏编辑需继续独立适配。雷蛇 V3 的传感器返回结构与某些 Viper 型号不同，不沿用其他型号的 LOD 写入命令。

固件更新、云账号、云配置、音乐灯效和进程联动不在当前版本范围。发布版本不包含固件刷写入口。

G2 Pro 保留现有官方驱动与音效组件，替换控制界面。JSON 配置保存当前可读取的音效参数，支持恢复完整配置或其中一部分；不包含系统音量和麦克风静音。导入先验证全部请求参数均可用，再按先关闭效果、调整数值、最后开启效果的次序写入；每项均读回核对，失败尝试恢复已尝试写入的参数。驱动崩溃、进程超时或设备断开仍可能阻止恢复，界面会报告失败。参数修改与恢复已有实测记录；声学效果还需按实际使用场景做听感对比。
