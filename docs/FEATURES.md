# 原驱动功能移植进度

本版本首先交付电量、常用性能设置和可复用框架。下表区分已接入与后续工作，避免把原驱动中的所有功能都显示成可用。

| 设备 | 本版本已接入 | 后续逐步移植 |
| --- | --- | --- |
| 雷蛇炼狱蝰蛇 V3 专业版 | 电量、充电、DPI 档位切换及当前档位编辑、回报率、休眠、省电阈值 | 按键重映射、宏、配置管理、Smart Tracking/非对称截止 |
| A5 Ultra 初代 | 电量、充电、DPI 档位切换及编辑、回报率、休眠、防抖、LOD、Motion Sync、直线修正、波纹控制 | 按键重映射、宏、配置管理、传感器旋转、DPI 档数和独立 Y 轴编辑 |
| G75 Pro | 电量、充电、回报率、休眠、灯效、亮度、速度、锁 Windows 键、低延迟 | 普通层/Fn 层改键、宏、灯色及逐键 RGB、配置导入导出 |
| G2 Pro | GAMING / CHAT / 麦克风音量、静音、十段 EQ、环绕开关与空间大小、响度均衡、声音提亮、动态低音、人声清晰、麦克风 / CHAT 降噪、变声 | 灯光、监听、配置预设、高级环绕模式 |

先实现各设备的备份、回滚和原始配置保留，再开放复杂改键与宏编辑。雷蛇 V3 的传感器返回结构与某些 Viper 型号不同，不沿用其他型号的 LOD 写入命令。

固件更新、云账号、云配置、音乐灯效和进程联动不在当前版本范围。发布版本不包含固件刷写入口。

G2 Pro 保留现有官方驱动与音效组件，替换控制界面。参数修改与恢复已实测；声学效果还需按实际使用场景做听感对比。
