# 安装与使用

## 第一次运行

1. 从 [主程序发布页](https://github.com/chenran0408/peripheral-desk/releases) 下载 Windows x64 ZIP，解压到可写文件夹，运行 `PeripheralDesk.exe`。
2. 首次使用首页为空，点击“添加设备驱动”打开“驱动仓库”。识别本机设备后，选择稳定版通道，安装自己准确型号对应的插件。不需要的设备可以不安装；不会根据开发者本机设备自动安装。新装设备插件后重启主程序。
3. 接入 USB 接收器或数据线，移动鼠标、按一下键盘，再刷新。首页亮色表示在线，暗色表示离线；缓存电量会标明“上次电量”。
4. 选择设备进入详情页。常用设置停止调整约 1.5 秒后写入，结果会显示在页面中。

设备插件来自 [公开驱动仓库](https://github.com/chenran0408/peripheral-desk-drivers)。主程序与插件分别更新，安装的设备型号必须准确：A5 Ultra 初代不能当作 A5 V2，G75 Pro 也不能直接代替其他 G75。

## 托盘与退出

左键托盘查看电量，右键打开主页、刷新或退出。窗口右上角关闭只会收起到托盘。

启用软件宏后，正常退出会等待恢复原按键。若提示设备断开或恢复失败，记录会保留；重新连接设备后打开“软件宏”，选择“停用 / 恢复原键”。强制结束进程无法完成退出恢复。

## 改键与软件宏

“改键”只开放当前设备确认可写的槽。雷蛇目前要求原始标记为 0，本机验证的是前进侧键（槽 5）；左键、标记 1 的槽与未知配置只读。

在“软件宏”新建名称、选择触发键，按每行一个步骤编辑，例如：

```text
按下 Ctrl
按下 C
延时 50
释放 C
释放 Ctrl
```

“保存定义”只保存本地；“启用软件宏”才临时改写所选按键。需要主程序常驻，只支持单次键盘动作，最多 128 步、总延时 30 秒；停用时恢复原绑定。F13–F24 保留为触发键，不能作为播放步骤。

三台设备的 F13 绑定与恢复已经验证，实际按键触发至前台窗口播放仍待实测。A5 本机宏页长度为 0，无法完整备份，板载宏拒写；G75、雷蛇板载宏也未开放。软件宏不等于写入设备的板载宏。

## G2 Pro

保留已安装的 HECATE / C-Media 声卡驱动与音效组件，日常可以关闭官方控制中心。在耳机页“连接音效组件”，选择官方安装目录的 x64 `osConfLib.dll`；当前只接入已校验的 C-Media 1.0.8.0 x64 文件。安装包和插件不附带该文件。

EQ 预设库可保存当前、切换、重命名、删除多套均衡器；每套只含十段与 EQ 开关，其他效果用音效 JSON 导入导出。默认曲线可自行调整，不是官方校准预设。

主程序与 G2 Pro 插件均更新到 0.4.2 后，“灯光开关”点击即生效，保留原模式和颜色。硬件关闭时仍可选择模式或颜色，再点击“应用并开灯”；其他灯效草稿单独提交。读取失败可“重新读取”或“尝试开灯”，后者仍需成功读取原开关才会写入。开关完成了实机切换和恢复；RGB、速度和模式尚未实机验证，也不能从设备完整读回，界面保存值不代表设备确认值。

## 备份与更新

更新前可从“配置备份”导出设备 JSON。导入只恢复本地记录；“应用到设备”是单独操作，无法安全确认的项目会跳过。软件宏导入不会自动启用。个人备份可能包含按键宏，反馈问题请使用匿名诊断。

主程序更新保留 `data` 文件夹；插件在“驱动仓库”独立更新、卸载或回退上一版。稳定版与预览版分别选择，预览通道不等于已实机验证。

离线安装从 [插件发布页](https://github.com/chenran0408/peripheral-desk-drivers/releases) 下载设备 ZIP，以及对应通道 `catalog-stable.json` 或 `catalog-preview.json` 和同名 `.json.sig`，放在同一文件夹。选择“离线安装…”打开 ZIP；使用与当前通道匹配的受信目录，不要双击或注册 DLL。
