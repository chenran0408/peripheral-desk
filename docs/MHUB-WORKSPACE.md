# 外设盒 · 迈从驱动中心

驱动中心基于迈从 M HUB 的前端和设备协议，由外设盒维护和发布。网页、设备协议代码、型号表和改键修复从电脑上的版本加载。官网发布新网页不会改变已安装的版本。

## 安装与连接

- 打开「设备调节」并点选实物。G75 Pro 改键、初代 A5 Ultra 常用设置直接在主窗口打开。要使用网页模板、磁轴编辑器或个人网页工作区，点右上角「本地 M HUB」，或从迈从原生设备页选择「更多原厂功能」。这些页面使用随包提供的本地资源和 Windows 上的 Microsoft Edge WebView2。
- 从电量详情点「打开设备设置」会带上所选设备。进入本地 M HUB 后，点顶栏「切换设备」可选择另一台。G75 Pro 已提交的改键会在切页后继续读回，可在「偏好设置 → 写入记录」查看结果。其他网页编辑器中的草稿仍需在离开前保存。
- Windows 直连仅用于外设盒随包或经更新安装的本地驱动中心。通过菜单手动打开自己保存的旧页面时，沿用该页面原有的连接方式。原厂选择框也可添加尚未覆盖直连的型号。
- 如果从旧版本以应用内更新方式升级，且电脑上还没有驱动中心资源，选择“安装或更新驱动中心”。下载的是外设盒 GitHub 发布页上与当前主程序匹配的资源包。下载并校验成功后才启用。已有的本地版本可离线使用。
- 关闭驱动中心后，设备页会恢复状态读取。设备设置、模板编辑和配置导入导出均在本地使用，无需账号。

## 磁轴键盘

在设备选择框连接受支持的磁轴键盘后，驱动中心会按识别结果打开本地编辑器。编辑器、布局预览、语言和厂商出厂键位都随安装包提供。具体可调的键程和触发功能取决于型号及固件。

## G75 Pro 再次改键

连接键盘，进入改键页，选择普通层、Fn 或 Fn2。页面会读取该层实际保存的映射。再次打开时，可以在上一次改键的基础上继续。无法显示名称的映射会显示为自定义编码或宏槽编号；改另一个键时仍会保留它。

## 修改界面、保留自己的版本

1. 在“驱动中心 → 打开驱动中心文件夹”中可编辑网页。入口是 `index.html`，外设盒界面在 `desk-hub/`，设备模块在 `assets/`。保存后选择“刷新当前页面”。
2. 跨版本保留的配色、缩放、CSS 和个人脚本位于“外观”菜单。自定义脚本及样式与资源包分开保存。
3. 要升级，请先更新外设盒，再选择“驱动中心 → 安装或更新驱动中心”。新快照保存到独立目录。想回到之前改过的版本，选择“切换本地版本”，打开旧版本的 `index.html`。同一快照的重复安装会保留原有修改。

## 维护与来源

维护范围以本地设备控制为主。账号、云同步及社区发布均在范围之外。社区模板仅保留一个可选方向：由用户在外设盒里主动获取公开模板，随后在本地选择和使用。

公开发布附件包括可编辑网页、外设盒的界面和协议修复、资源清单和构建方式。项目维护者审阅新的上游快照、应用本项目的修改、构建并发布资源包。外设盒不通过迈从网站、CDN 或网页自身的在线更新器获取新版本。驱动中心在本机提供旧网页仍然使用的型号表地址。本地快照中缺失的图片不会通过网络补取。

按使用者从迈从官方交流群转述的使用条件，迈从网页资源仅供开源项目非商业使用，不得用于牟利或商业化。外设盒自身代码和各第三方资源的归属与条款见随包说明。
