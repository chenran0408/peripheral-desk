# 迈从 M HUB 个性化工作区

在驱动商店选择迈从品牌，或在迈从设备详情点击“打开官方 M HUB”。Windows 需要 Microsoft Edge WebView2。首次连接时，选中你要设置的实际设备。

## 改外观

打开窗口的“外观”菜单，可直接选强调色和缩放。要调整文字、布局或间距，选“编辑个人样式”，在记事本保存 CSS 后选“重新应用样式”。个人样式应用于在线站点和本地副本，独立于网页更新保存。迈从目前的界面变量包括 `--du-accent-blue`、`--du-radius-md` 和 `--du-font-size-md`。

## 改页面和交互

1. 打开“工作区 → 下载或更新可编辑副本”。完成后选择打开本地副本。
2. 选择“打开网页文件夹”。`index.html` 是网页入口，`assets` 里是设备页面、交互脚本及样式。这里保留厂商公开部署的构建文件。
3. 修改后选择“刷新当前页面”。想使用未经编辑的官方界面，选择“返回官方网站”。下次打开 M HUB 会记住你选用的模式。
4. M HUB 更新后可再次下载。每一版存入独立目录，同版已有文件会保留。选择“切换已保存的版本”，可打开旧目录下的 `index.html`。

本地副本使用独立的网页地址。浏览器可能再次请你选择设备，需登录的服务也可能要求重新登录。云端社区、型号资料和固件下载依赖厂商服务。关闭 M HUB，外设盒恢复本地设备访问。主程序安装包只包含工作区工具，选择下载时才从官网获取网页内容。

## 直接在外设盒调整鼠标

在驱动商店安装与鼠标和接收器对应的插件。支持的型号会在设备详情显示“指针与性能”。选择板载配置、DPI 档位或参数，输入新值后应用。参数范围和枚举取自该型号的插件。设备断开或拒绝写入时，窗口会显示读回和恢复结果。这些本地参数可在离线时调整。

## 功能范围

| 功能 | 入口与运行条件 |
| --- | --- |
| 型号专属设置、按键、宏、灯效和键盘工具 | 本地副本运行同版网页入口和设备模块，所显示的项目由 M HUB 根据连接型号决定。 |
| 社区、账户、云模板、固件检查与下载 | 由厂商在线服务提供。可从同一窗口切回官方网站。 |
| 界面主题、个人样式、缩放 | 外观菜单可随时调整。 |
| 已移植的鼠标板载参数 | “指针与性能”通过本机驱动插件读写，可逐项读回。 |
