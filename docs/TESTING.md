2026-10-21，Windows x64，本机三台实物设备。

- Rust fmt、Clippy（警告视为错误）、release 构建通过。
- 17 项常规测试通过；3 项实机测试默认忽略，不在 CI 操作设备。
- 同值写入验证通过：三台设备 DPI/回报率/休眠等原有设置，以及新增的档位与高级参数。
- 往返验证通过：雷蛇 DPI、档位、省电阈值；A5 DPI、档位、防抖、LOD、Motion Sync、直线修正、波纹控制；G75 锁 Windows 键、低延迟、亮度、速度和灯效。测试切换后恢复原值。

- 20 项常规测试通过，fmt、Clippy 和 release 构建通过。
- G2 Pro 三路音量临时降低 1% 并恢复精确原值，麦克风静音按原值读写，通过。
- 25 项音效参数分别修改、独立进程读回、检查其他字段不变并恢复，最后完整参数表与基线一致。包含全部十段 EQ、开关、环绕空间、增强强度、降噪与变声。

- 发现雷蛇密集请求偶发忙碌，等待首个回复时间改为 80 ms 后，DPI / 回报率 / 休眠同值回归通过；只读查询增加一次有界重试，写入不自动重复。
- 无线设备高级同值回归曾通过；随后长时间闲置使雷蛇返回超时，最终完整往返回归未能完成。因此本次作为预览版发布，不能称全部四项实机测试均通过。雷蛇测试中的原值恢复已确认成功。
- Windows 音频增强禁用场景有显式读取与拒写保护；实机切换禁用标志的测试被注册表访问限制阻止，确认原标志仍为 0，没有更改权限或系统保护。
- 未播放测试声音或录制麦克风；本版本是参数控制验证，未完成声学测量、全模式听感对比或用户此前未能复现的官方驱动 bug 验证。

此前测试使用临时 Windows 系统防睡眠请求；读取操作不能保证阻止外设固件休眠。本轮确认 A5 与 G75 的不休眠值为 0 后，才开放该选项。未向雷蛇写入未知的禁用休眠数值。

## 0.3.0 深度适配

本轮 32 项常规测试通过，fmt、Clippy（警告视为错误）及 release 构建通过。7 项实机项目均已分别通过，包含失败项修复后的复测；并非首次连续批次零失败。

- G75 `0x49` 只读取得 490 字节灯色块，前 42 字节与原驱动调色表和首个模式数据一致。
- G75 新功能实物往返测试通过：临时选择呼吸/单色，切换一个颜色预设、单色/多色、Mac 模式与 Win 键锁定互斥、休眠 0。每次核对完整配置，最终原 128 字节性能块与原 490 字节灯色块均精确恢复。
- G75 测试期间可显式设置 `PERIPHERAL_DESK_G75_KEEP_AWAKE=1`，在往返验收成功且原块恢复后，单独写入 Sleep 0。该测试会打印原休眠秒数，测试结束需按原值恢复；不会随日常启动自动启用。
- 常规测试补充模式能力边界、只修改当前 RGB、保留未知颜色与无关字节、Mac/Win 键锁互斥、音效 JSON 型号/版本/范围拒绝、音效批量中途失败恢复，以及指定设备刷新。常规测试不访问真实硬件。
- G2 Pro 本轮再次通过 25 项音效参数逐项往返，其他参数均未变化，最终全表恢复；JSON 导出 25 项、批量修改 2 项后读回、拒绝错误型号/版本/越界值且不改设置、重新导入原文件恢复全表，全部通过。
- A5 不休眠、电竞模式、传感器正负角度、6→5→6 档数均通过完整 63 字节读回及恢复；会删除当前档位的缩档请求被拒绝，完整配置未变化。
- 雷蛇与此前三外设的四项实机回归在唤醒后全部通过，补齐预览版未完成的往返验证。

实机测试默认忽略，按需指定项目单独运行，避免一次执行所有测试后无法定位设备状态：

```powershell
cargo test keyboard::tests::live_g75_color_format -- --ignored --exact --nocapture --test-threads=1
cargo test keyboard::tests::live_g75_new_features_restore_full_blocks -- --ignored --exact --nocapture --test-threads=1
```

测试需保持设备连接、唤醒，并关闭其他控制中心的设备页。测试按原块恢复后再断言，但设备断连、驱动故障或进程被强制结束仍可能阻止恢复；检查日志中的恢复结果。该测试没有覆盖普通/Fn 层改键、宏或逐键灯，不能据此声称支持。
