# 验证记录

2026-10-21，Windows x64，本机三台实物设备。

- Rust fmt、Clippy（警告视为错误）、release 构建通过。
- 17 项常规测试通过；3 项实机测试默认忽略，不在 CI 操作设备。
- 同值写入验证通过：三台设备 DPI/回报率/休眠等原有设置，以及新增的档位与高级参数。
- 往返验证通过：雷蛇 DPI、档位、省电阈值；A5 DPI、档位、防抖、LOD、Motion Sync、直线修正、波纹控制；G75 锁 Windows 键、低延迟、亮度、速度和灯效。测试切换后恢复原值。
- G75 偶发丢失 ACK 时只在完整配置精确读回匹配后判定成功。

覆盖的接口：1532:00B7、3837:100C、3554:FA09。未实测的有线标识、蓝牙或其他硬件版本不据此宣称兼容。

GUI 采用真实设备状态进行人工检查。设备休眠时的新读数不可用，缓存电量不作为在线读数。

电量浮窗已通过实际窗口检查；0.2.1 加宽百分比列，避免 100% 被截断。

## 0.3.0-preview.1

- 20 项常规测试通过，fmt、Clippy 和 release 构建通过。
- G2 Pro 三路音量临时降低 1% 并恢复精确原值，麦克风静音按原值读写，通过。
- 25 项音效参数分别修改、独立进程读回、检查其他字段不变并恢复，最后完整参数表与基线一致。包含全部十段 EQ、开关、环绕空间、增强强度、降噪与变声。
- GUI 中 EQ 按钮修改已单独从 SDK 读回确认，随后恢复；四设备首页和耳机页面已做实际窗口检查。
- 缺少 SDK 配置时三路音量和静音仍可读，音效区返回明确错误，不伪造能力。
- 发现雷蛇密集请求偶发忙碌，等待首个回复时间改为 80 ms 后，DPI / 回报率 / 休眠同值回归通过；只读查询增加一次有界重试，写入不自动重复。
- 无线设备高级同值回归曾通过；随后长时间闲置使雷蛇返回超时，最终完整往返回归未能完成。因此本次作为预览版发布，不能称全部四项实机测试均通过。雷蛇测试中的原值恢复已确认成功。
- Windows 音频增强禁用场景有显式读取与拒写保护；实机切换禁用标志的测试被注册表访问限制阻止，确认原标志仍为 0，没有更改权限或系统保护。
- 未播放测试声音或录制麦克风；本版本是参数控制验证，未完成声学测量、全模式听感对比或用户此前未能复现的官方驱动 bug 验证。

测试时使用临时 Windows 系统防睡眠请求；外设固件的自主休眠无法保证由读取操作阻止。未写入未知的禁用休眠数值。
